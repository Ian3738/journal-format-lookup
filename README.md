# 投稿格式速查台

52 本 TSSCI 與 SSCI 期刊的投稿格式速查工具。字數上限、摘要規定、參考文獻體例、審查流程與費用集中在一頁，可篩選、可並排比較，也能依選定期刊產生投稿前檢查清單。

**線上版：** https://ian3738.github.io/journal-format-lookup/

單一 HTML 檔，沒有相依套件，也不需要建置流程。下載 `index.html` 用瀏覽器打開就能離線使用。

---

## 四個分頁

**瀏覽**　左側可依索引分級、學科領域、費用型態、資料查證程度篩選。卡片正面直接顯示字數上限、摘要字數、參考文獻格式這三個最常查的欄位，點卡片展開完整規範。

**比較**　選兩本以上並排對照，只有與其他期刊不同的欄位會標色，決定投稿標的時最省時間。

**檢查清單**　選定期刊後，依該刊實際規定產生逐項清單，可直接勾選。投稿前最後一輪自檢用。

**APA 7**　常用體例速查，含中文期刊特有的在地規範：文獻中外文排序、中文文獻英譯要求、全形半形標點、統計符號斜體規則、圖表標題位置。

## 資料來源

期刊名單取自國家科學及技術委員會人文社會科學研究中心「臺灣人文及社會科學期刊評比暨核心期刊收錄」官方名單：

| 名單 | 涵蓋學門 | 適用期間 |
| --- | --- | --- |
| 2025 年名單 | 教育學（含體育學、圖書資訊學）、政治學、經濟學、區域研究及地理、綜合類 | 2026-01-01 至 2028-12-31 |
| 2024 年名單 | 藝術學、人類學及族群研究、社會學及社福社工、心理學、法律學、管理學 | 2025-01-01 至 2027-12-31 |

格式規範則逐本取自各刊自己公告的稿約、徵稿辦法或撰稿體例。**沒有查到的欄位一律寫「須查官網」或「未載明」，不做推測填補。**

### 三種查證程度

每筆資料都標了查證程度，在卡片右下角與詳情頁都看得到：

| 標示 | 意思 | 本數 |
| --- | --- | --- |
| ● 已核對官方稿約 | 逐字讀過該刊官方稿約或撰稿體例全文，欄位數字直接來自原文 | 13 |
| ◐ 官方頁面摘錄 | 取自該刊官方頁面，但未能取得完整稿約文件，可能有未涵蓋的細項 | 15 |
| ○ 僅收錄分級 | 只確認了收錄狀態與評比級別，格式細節未查證 | 24 |

國際期刊的資料之所以不如中文期刊完整，是因為 ScienceDirect、Wiley Online Library 與部分 SAGE、Taylor & Francis 的作者指南頁面會阻擋自動存取。這些期刊的卡片都附了投稿指南的直達連結。

### 使用前請注意

- **稿約會改版。** 本站資料查證基準日為 2026 年 8 月 28 日。這裡的資料用來快速篩選與比較，不能取代官方文件——正式投稿前請以該刊官網當下的版本為準。
- **JCR 分區逐年變動。** 標示的 Q1／Q2 僅供大致定位，同一本期刊在不同 category 下的分區也可能不同。
- **TSSCI 沒有 Q1／Q2。** 臺灣核心期刊用的是第一級、第二級（第三級不屬核心期刊），與 JCR 四分位是兩套不同的制度。
- **字數的計算範圍各刊不同。** 有的含參考文獻與圖表、有的不含；《教育心理學報》與《測驗學刊》同時卡字數與頁數。看數字時要一併看括號裡的計算方式。

## 自行增修資料

期刊資料寫在 `index.html` 內的 `const J = [...]` 陣列，直接編輯即可，欄位如下：

```js
{
  id:"jres",                                  // 唯一識別碼
  name:"教育科學研究期刊",                      // 中文刊名
  en:"Journal of Research in Education Sciences",
  pub:"國立臺灣師範大學圖書館出版中心",           // 出版者
  issn:"2073-753X",
  idx:"TSSCI",                                // TSSCI / SSCI / 非核心
  tier:"第一級",                               // 第一級・第二級・第三級・Q1・Q2・各學門核心
  field:["教育學"],                            // 可多個，見 FIELDS 常數
  verified:"official",                        // official / partial / listed
  scope:"…", freq:"…", intake:"…",             // 徵稿範圍、出刊頻率、收稿方式
  wcZh:"20,000 字", wcEn:"7,500 字", wcNote:"…", // 字數上限與計算範圍
  absZh:"300–500 字", absEn:"…", absNote:"…",   // 摘要
  kw:"3–5 個", kwNote:"…",                     // 關鍵詞
  ref:"APA 第 7 版",                           // 參考文獻格式
  layout:"…", heads:"…",                       // 版面設定、標題層級
  review:"雙向匿名審查", timeline:"…",           // 審查方式與時程
  fee:"…", feeType:"paid",                     // free / paid / hybrid / apc / unknown
  oa:true,                                     // 選填，開放取用
  system:"https://…", site:"https://…",        // 投稿系統、期刊官網
  contact:"…",
  alerts:["…"],                                // 特別注意事項，會顯示在詳情頁與檢查清單
  src:"…"                                      // 資料來源說明
}
```

新增領域請一併加進 `FIELDS` 常數，新增分級請加進 `TIERS`。側邊篩選的計數會自動更新。

### 查稿約的兩個門路

- 台灣期刊：華藝線上圖書館的 `https://www.airitilibrary.com/jnltitledo/{ISSN去連字號}-n.pdf` 可直接取得多數期刊的官方稿約 PDF，是最快的來源。
- 國際期刊：出版商網站多半擋自動存取，直接開卡片裡的投稿指南連結最省事。
