# 國內外期刊投稿格式平台

52 本 TSSCI 與 SSCI 期刊的投稿格式速查工具。字數上限、摘要規定、參考文獻體例、審查流程與費用集中在一頁，可篩選、可並排比較，也能依選定期刊產生投稿前檢查清單。

**線上版：** https://ian3738.github.io/journal-format-lookup/

單一 HTML 檔，沒有相依套件，也不需要建置流程。下載 `index.html` 用瀏覽器打開就能離線使用。桌機、平板、手機都能用，另有列印樣式，可以把檢查清單印出來帶著走。

---

## 頁面結構

**首頁**　收錄概況、分級分佈，以及依索引分級或學科領域的入口。點任一入口會帶著篩選條件跳到期刊總覽。

**期刊總覽**　依索引體系與學門分組排列，左側可再依領域、費用型態、資料查證程度縮小範圍。卡片正面直接顯示字數上限、摘要字數、參考文獻格式這三個最常查的欄位，點卡片展開完整規範。

**比較**　選兩本以上並排對照，只有與其他期刊不同的欄位會標色，決定投稿標的時最省時間。

**檢查清單**　選定期刊後，依該刊實際規定產生逐項清單，可直接勾選。投稿前最後一輪自檢用。

**APA 7**　常用體例速查，含中文期刊特有的在地規範：文獻中外文排序、中文文獻英譯要求、全形半形標點、統計符號斜體規則、圖表標題位置。

**資料說明**　資料來源、三種查證程度的定義，以及使用時的注意事項。

**稿件檢查**　貼上全文或上傳 `.docx`，算字數、掃匿名審查殘留、對照本刊規定。詳見下一節。

鍵盤：按 `/` 跳到搜尋框，`Esc` 關閉期刊詳情，點左上角站名回首頁。

### 版面斷點

斷點取自版面實際斷裂的位置，不是裝置型號：

| 寬度 | 變化 |
| --- | --- |
| 1100px 以下 | 側邊篩選改為頂部橫向排列，預設收起，避免 32 個選項把卡片推出螢幕 |
| 820px 以下 | 導覽列重排（搜尋獨占一行、分頁可橫向捲動），期刊卡片改單欄 |
| 600px 以下 | 縮排距與字級，抽屜全寬，搜尋框固定 16px 以免 iOS 聚焦時自動放大 |
| 400px 以下 | 再縮字級與徽章 |

觸控裝置（`hover:none`）另外放大可點目標並停用 hover 位移。比較表是否顯示「可左右滑動」由實際捲動範圍決定，不用斷點猜。

### 稿件檢查能做什麼、不能做什麼

**會做的**：算字數（摘要／正文／參考文獻分開列，依該刊的計算範圍決定拿哪個比對）、比對摘要字數與關鍵詞個數、掃出中文脈絡誤用的半形標點與 APA 第 7 版的常見寫法問題、檢查匿名審查可能殘留的個人資訊，以及**把頁面邊界、字型、字級、行距直接套到你的 Word 檔並另存新檔**。

**不會做的**：不改稿件的文字內容。標點與引用格式只回報位置與該在 Word 裡搜尋什麼，因為那要動到你寫的字。

### 套版是怎麼做到不弄壞原檔的

關鍵在於**不重建文件**。`.docx` 是一個 zip，套版時逐 entry 把原始壓縮位元組直接複製過去，只解壓並置換 `word/document.xml` 的 `sectPr`（紙張與邊界）與 `word/styles.xml` 的 `docDefaults`（字型、字級、行距）這兩處。其餘每一個內部檔案連解壓都不做，所以圖片、圖說、表格、註腳、方程式、Zotero／EndNote 的功能變數不可能在過程中受損。

用一份 3.86 MB、含 24 張圖片的真實論文實測：

| 檢查 | 結果 |
| --- | --- |
| zip 結構 | 無錯誤 |
| 內部檔案數 | 38 → 38，0 遺失 |
| 24 張圖片 | CRC 與原檔完全相同 |
| 註腳／註解／編號／關聯 | 原封不動 |
| 文字內容 | 24,604 bytes，與原檔一字不差 |
| 版面 | A4、邊界 1803 twips＝3.18 cm 正確寫入 |
| 實際變動 | 只有 `document.xml` 與 `styles.xml` |

表單的預設值會從該刊 `layout` 欄位的原文自動讀出（《教育科學研究期刊》可讀出全部六項：上下 2.54、左右 3.18、新細明體、Times New Roman、12 級、單行間距），讀不到的欄位標明是通用預設值，請自行對照稿約。

有一個預設勾選的選項是**清除文中手動設定的字型與字級**。中文論文多半是逐段手動設字型的，不清的話新的預設會被蓋掉、等於沒套。這個動作只清字型與字級，粗體、斜體、底線、顏色、對齊、縮排都不碰。

**兩道安全機制**：文件若有多個章節設定（通常表示中間有橫向頁面，例如放大表格那幾頁），一律不提供自動套用，因為套同一組邊界會把那些頁面弄壞；上傳檔案後又手動改過文字框內容的，也會停用套版，避免報告與產出的檔案對不起來。

檔案一律另存新檔，原稿不會被動到。存下來之後請在 Word 裡開一次確認。

**判定一律三態**，永遠不會出現「通過」或「符合本刊格式」：

| 狀態 | 意思 |
| --- | --- |
| 在範圍內／臨界／超出 | 有資料可比對。與上限相差 5% 以內一律標「臨界」，請以 Word 的字數統計為準 |
| 不做判定 | 本刊規定一句話裡有兩個數字（例如「15,000 字為上限，如超過以 20,000 字為原則」），本站不替你選一個 |
| 無法檢查 | 本站沒有這本期刊的數字。**這不等於通過** |

報告最後固定有一區「本次沒有檢查的項目」，不可摺疊，逐條寫明原因。

**誤報的防範**是這套規則能不能用的關鍵。文字規則一律跳過六種保護區：參考文獻、英文摘要、附錄、引號內的直接引文、網址與 DOI、程式碼與數學式。用一份 7,000 字的真實中文論文實測，只報出 3 個真問題、0 誤報——`註. ` 是 APA 表格註解的正確寫法，`SE差異 = √(SE₁² + SE₂²)` 裡的下標變數名不該補空格，這兩類都正確放行了。

**`.docx` 讀取**用瀏覽器原生的 `DecompressionStream('deflate-raw')` 解 zip、`DOMParser` 解 OOXML，沒有任何外部函式庫。只解 `word/document.xml` 等需要的 part，圖片一個位元組都不碰，4 MB 的檔案約 200 毫秒。跳過 `w:instrText`（Zotero、EndNote 的欄位碼，不跳會混進正文汙染字數）與 `w:delText`。另外會讀 `docProps/core.xml`，因為 Word 檔案內容資訊裡的作者名是雙向匿名審查最常見的破口，作者本人幾乎不會想到要清。

檔案完全在瀏覽器裡處理，沒有上傳到任何地方，因為這個網站沒有後端。

### 期刊怎麼分組

各學門的評比是分開進行的——同樣掛「第一級」，教育學門與政治學門是兩份互不相干的名單，混在一起看會誤判競爭程度。所以總覽依索引體系與學門分成七組：

| 分組 | 本數 | 說明 |
| --- | --- | --- |
| TSSCI 教育學門・第一級 | 12 | 2025 年評比，適用至 2028 年底 |
| TSSCI 教育學門・第二級 | 7 | 同屬核心期刊，收錄地位與第一級相同 |
| TSSCI 心理學門 | 7 | 2024 年評比，含教育心理、輔導諮商、測驗評量 |
| TSSCI 社會・政治・管理學門 | 7 | 跨足教育議題時的替代管道 |
| SSCI Q1 | 16 | JCR 第一四分位 |
| SSCI Q2 | 2 | JCR 第二四分位 |
| 非核心・領域相關 | 1 | 2025 年評比第三級，不屬核心期刊但為該主題少數專門刊物 |

## 資料來源

期刊名單取自國家科學及技術委員會人文社會科學研究中心「臺灣人文及社會科學期刊評比暨核心期刊收錄」官方名單：

| 名單 | 涵蓋學門 | 適用期間 |
| --- | --- | --- |
| 2025 年名單 | 教育學（含體育學、圖書資訊學）、政治學、經濟學、區域研究及地理、綜合類 | 2026-01-01 至 2028-12-31 |
| 2024 年名單 | 藝術學、人類學及族群研究、社會學及社福社工、心理學、法律學、管理學 | 2025-01-01 至 2027-12-31 |

格式規範則逐本取自各刊自己公告的稿約、徵稿辦法或撰稿體例。**沒有查到的欄位一律寫「須查官網」或「未載明」，不做推測填補。**

### 三種查證程度

每筆資料都標了查證程度，在卡片右下角與詳情頁都看得到：

| 標示 | 意思 | 本數 |
| --- | --- | --- |
| ● 已核對官方稿約 | 逐字讀過該刊官方稿約或撰稿體例全文，欄位數字直接來自原文 | 39 |
| ◐ 官方頁面摘錄 | 取自該刊官方頁面，但未能取得完整稿約文件，可能有未涵蓋的細項 | 13 |
| ○ 僅收錄分級 | 只確認了收錄狀態與評比級別，格式細節未查證 | 0 |

剩下 13 本「官方頁面摘錄」分兩種情形。一種是資料取自網頁存檔而非現行頁面（《教育學報》《臺灣數學教育期刊》與兩本國際期刊），這幾本的卡片上都寫明了存檔日期。另一種是 ScienceDirect、Wiley Online Library 與部分 SAGE、Taylor & Francis 的作者指南頁面阻擋自動存取，只能取得期刊層級的資訊。兩種情形都附了投稿指南的直達連結。

稿約自己講不清楚的地方，本站照原樣呈現，不替使用者選一個答案：

- 《Interactive Learning Environments》同一節稿約寫了兩個不同的字數上限，兩個都列出來。
- 《Journal of Educational Computing Research》官方只寫「多數已刊登作者不超過 10,000 字」，那是描述不是規定，所以不寫成上限。
- 《社會工作與社會政策實務》官網現行版與紙本徵稿簡約的字數換算不過來，兩個版本並陳。
- 《Assessment & Evaluation in Higher Education》兩個官方頁面對審查人數說法不同，兩種說法都寫。

### 暫停收稿

《教育學報》（香港中文大學）自 2026 年 8 月 1 日起暫停接受新投稿。這件事會讓人白做工，所以在卡片、檢查清單、稿件檢查三個地方都會出現警告，不必點開詳情才看得到。這是全站唯一用實心底色的標籤。

### 使用前請注意

- **稿約會改版。** 本站資料查證基準日為 2026 年 8 月 29 日。這裡的資料用來快速篩選與比較，不能取代官方文件——正式投稿前請以該刊官網當下的版本為準。
- **JCR 分區逐年變動。** 標示的 Q1／Q2 僅供大致定位，同一本期刊在不同 category 下的分區也可能不同。
- **TSSCI 沒有 Q1／Q2。** 臺灣核心期刊用的是第一級、第二級（第三級不屬核心期刊），與 JCR 四分位是兩套不同的制度。
- **字數的計算範圍各刊不同。** 有的含參考文獻與圖表、有的不含；《教育心理學報》與《測驗學刊》同時卡字數與頁數。看數字時要一併看括號裡的計算方式。

## 自行增修資料

期刊資料寫在 `index.html` 內的 `const J = [...]` 陣列，直接編輯即可，欄位如下：

```js
{
  id:"jres",                                  // 唯一識別碼
  name:"教育科學研究期刊",                      // 中文刊名
  en:"Journal of Research in Education Sciences",
  pub:"國立臺灣師範大學圖書館出版中心",           // 出版者
  issn:"2073-753X",
  idx:"TSSCI",                                // TSSCI / SSCI / 非核心
  tier:"第一級",                               // 第一級・第二級・第三級・Q1・Q2・各學門核心
  field:["教育學"],                            // 可多個，見 FIELDS 常數
  verified:"official",                        // official / partial / listed
  scope:"…", freq:"…", intake:"…",             // 徵稿範圍、出刊頻率、收稿方式
  wcZh:"20,000 字", wcEn:"7,500 字", wcNote:"…", // 字數上限與計算範圍
  absZh:"300–500 字", absEn:"…", absNote:"…",   // 摘要
  kw:"3–5 個", kwNote:"…",                     // 關鍵詞
  ref:"APA 第 7 版",                           // 參考文獻格式
  layout:"…", heads:"…",                       // 版面設定、標題層級
  review:"雙向匿名審查", timeline:"…",           // 審查方式與時程
  fee:"…", feeType:"paid",                     // free / paid / hybrid / apc / unknown
  oa:true,                                     // 選填，開放取用
  system:"https://…", site:"https://…",        // 投稿系統、期刊官網
  contact:"…",
  alerts:["…"],                                // 特別注意事項，會顯示在詳情頁與檢查清單
  src:"…"                                      // 資料來源說明
}
```

新增領域請一併加進 `FIELDS` 常數。分組規則寫在 `GROUPS` 陣列，每組用 `match` 函式判定歸屬；學門歸屬另有 `DIVISION` 對照表（未列出者預設為教育學門）。首頁入口、側邊篩選與總覽分組共用同一套 `GROUPS`，改一處三處同步，計數也會自動更新。

### 查稿約的兩個門路

- 台灣期刊：華藝線上圖書館的 `https://www.airitilibrary.com/jnltitledo/{ISSN去連字號}-n.pdf` 可直接取得多數期刊的官方稿約 PDF，是最快的來源。
- 國際期刊：出版商網站多半擋自動存取，直接開卡片裡的投稿指南連結最省事。
